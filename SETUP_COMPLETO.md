# 🎉 Setup Completo - Cecília 1 Ano\n\n## Visão Geral\n\nEste guia vai te ensinar como colocar seu site funcionando com:\n- **Netlify Functions** (backend serverless)\n- **Supabase** (banco de dados PostgreSQL)\n- **Mural de recadinhos** (persistente)\n- **RSVP/Confirmação de presença** (persistente)\n\n---\n\n## 📋 Passo 1: Criar Banco de Dados no Supabase\n\n### 1.1 Criar conta e projeto\n\n1. Acesse [supabase.com](https://supabase.com)\n2. Clique em **Sign Up**\n3. Use email ou GitHub para se registrar\n4. Crie um novo projeto:\n   - **Name**: `cecilia-1ano`\n   - **Region**: Escolha a mais perto de você\n   - **Password**: Crie uma senha segura\n\n### 1.2 Criar tabela de storage\n\n1. No dashboard Supabase, vá para **SQL Editor**\n2. Clique em **New Query**\n3. Cole este código:\n\n```sql\nCREATE TABLE storage_data (\n  id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY,\n  key TEXT UNIQUE NOT NULL,\n  value TEXT NOT NULL,\n  is_public BOOLEAN DEFAULT false,\n  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()\n);\n\nCREATE INDEX idx_key ON storage_data(key);\nCREATE INDEX idx_prefix ON storage_data(key text_pattern_ops);\n```\n\n4. Clique em **Run** (triângulo verde)\n\n### 1.3 Configurar Row Level Security (RLS)\n\n1. Vá para **Authentication > Policies**\n2. Selecione a tabela `storage_data`\n3. Clique em **Enable RLS**\n4. Crie duas policies:\n\n**Policy 1 - SELECT (Leitura Pública)**\n```sql\n(is_public = true) OR (auth.role() = 'authenticated')\n```\n\n**Policy 2 - INSERT/UPDATE (Escrita)**\n```sql\nauth.role() = 'service_role'\n```\n\n### 1.4 Copiar Credenciais\n\n1. Vá para **Settings > API** (canto inferior esquerdo)\n2. Copie e guarde:\n   - **Project URL** → `SUPABASE_URL`\n   - **Anon public key** → `SUPABASE_ANON_KEY`\n   - **Service role secret key** → `SUPABASE_SERVICE_ROLE_KEY`\n\n⚠️ **IMPORTANTE**: Guarde a `SERVICE_ROLE_KEY` em segurança! Ela é como a senha do seu banco.\n\n---\n\n## 🔧 Passo 2: Configurar Variáveis de Ambiente\n\n### 2.1 Arquivo Local (`.env`)\n\nNa raiz do projeto, crie um arquivo chamado `.env`:\n\n```env\nSUPABASE_URL=https://seu-projeto.supabase.co\nSUPABASE_ANON_KEY=eyJhbGc...(sua chave aqui)\nSUPABASE_SERVICE_ROLE_KEY=eyJhbGc...(sua chave de serviço aqui)\n```\n\n### 2.2 No Netlify\n\n1. Acesse [netlify.com](https://netlify.com)\n2. Clique em **Sign up** (ou faça login)\n3. Conecte seu **GitHub**\n4. Selecione o repositório `claude-artifacts`\n5. Clique em **Deploy**\n6. Após o deploy, vá para:\n   - **Site settings** → **Build & deploy** → **Environment**\n7. Clique em **Edit variables**\n8. Adicione as 3 variáveis:\n   - `SUPABASE_URL`\n   - `SUPABASE_ANON_KEY`\n   - `SUPABASE_SERVICE_ROLE_KEY`\n\n---\n\n## 🚀 Passo 3: Testar Localmente\n\n### 3.1 Instalar Dependências\n\n```bash\nnpm install\n```\n\n### 3.2 Rodar com Netlify Dev\n\n```bash\nnpm run dev\n```\n\nO site vai rodar em `http://localhost:8888`\n\n### 3.3 Testar Funcionalidades\n\n1. **Mural de recadinhos**:\n   - Preencha nome e mensagem\n   - Clique em \"Postar recadinho\"\n   - A mensagem deve aparecer abaixo\n\n2. **RSVP**:\n   - Clique em \"Confirmar presença\"\n   - Preencha nome, adultos, crianças\n   - Clique em \"Enviar confirmação\"\n   - Deve aparecer \"Presença confirmada!\"\n\n### 3.4 Verificar Dados no Supabase\n\n1. Volte ao dashboard Supabase\n2. Vá para **Editor > storage_data**\n3. Você deve ver as linhas que inseriu!\n\n---\n\n## 🌐 Passo 4: Deploy em Produção\n\n### 4.1 Fazer Push para GitHub\n\n```bash\ngit add .\ngit commit -m \"chore: setup completo com Netlify + Supabase\"\ngit push origin setup-netlify\n```\n\n### 4.2 Criar Pull Request\n\n1. No GitHub, vá para seu repositório\n2. Clique em **Pull Requests**\n3. Clique em **New Pull Request**\n4. Selecione `setup-netlify` → `main`\n5. Clique em **Create Pull Request**\n6. Clique em **Merge Pull Request**\n\n### 4.3 Netlify faz Deploy Automaticamente\n\n1. Vá para seu site no Netlify\n2. Vá para **Deploys**\n3. Aguarde o build (leva ~1 min)\n4. Quando estiver verde ✅, seu site está online!\n\n---\n\n## 📱 Onde Acessar\n\nSeu site estará em:\n```\nhttps://seu-site.netlify.app\n```\n\nVocê pode encontrar o URL exato em:\n- **Netlify Dashboard > Site Overview**\n- Ou em **Site settings > General > Site details**\n\n---\n\n## 🐛 Troubleshooting\n\n### ❌ \"storage is not defined\"\n**Solução**: Adicione esta linha no HTML (já está, mas verifique):\n```html\n<script src=\"/storage-api.js\"></script>\n```\n\n### ❌ Erro 403 no Supabase\n**Solução**: Verifique se a `SERVICE_ROLE_KEY` está correta nas variáveis de ambiente do Netlify.\n\n### ❌ Functions não funcionam localmente\n**Solução**: Instale Netlify CLI:\n```bash\nnpm install -g netlify-cli\n```\n\nE rode:\n```bash\nnetlify dev\n```\n\n### ❌ Dados não aparecem no Supabase\n**Solução**: Verifique o console do navegador (F12 > Console) para ver erros.\n\n### ❌ Site fica em branco após deploy\n**Solução**: Verifique os logs do Netlify:\n1. **Netlify Dashboard > Deploys**\n2. Clique no deploy mais recente\n3. Vá para **Deploy log**\n4. Procure por erros\n\n---\n\n## 📊 Estrutura de Dados\n\nOs dados são salvos na tabela `storage_data` com a seguinte estrutura:\n\n### Mural de recadinhos\n```json\n{\n  \"key\": \"message:1696958400000:abc123\",\n  \"value\": {\"name\": \"Maria\", \"text\": \"Que alegria!\", \"timestamp\": \"2024-10-10T20:00:00Z\"}\n}\n```\n\n### RSVP/Confirmação\n```json\n{\n  \"key\": \"rsvp:1696958400000:xyz789\",\n  \"value\": {\"name\": \"João\", \"adults\": 2, \"kids\": 1, \"obs\": \"Sem leite\", \"timestamp\": \"2024-10-10T20:00:00Z\"}\n}\n```\n\n---\n\n## ✅ Checklist Final\n\n- [ ] Projeto Supabase criado\n- [ ] Tabela `storage_data` criada\n- [ ] RLS configurado\n- [ ] Credenciais copiadas\n- [ ] `.env` criado localmente\n- [ ] Variáveis adicionadas no Netlify\n- [ ] Testado localmente com `npm run dev`\n- [ ] Mural de recadinhos funcionando\n- [ ] RSVP funcionando\n- [ ] Dados aparecendo no Supabase\n- [ ] Push feito para GitHub\n- [ ] Deploy em produção ✅\n\n---\n\n## 🎯 Próximos Passos\n\n1.
